#小惑星 (Shōwakusei)

##Description
Shōwakusei, translates to astroid or planetoid in Japanese.
This project is a minimally viable clone of the classic game Asteroids built in the Unity Game Engine.


##Motivation
Initially started as I was following the tutorial on making the core logic for asteroids "Let's Create: Asteroids in Unity" by the youtube channel Firnox.

I nearly immediately deviated from their design and developed practically all the code from scratch.

Features basic custom asteroid and vector based ship graphics

The unique feature of this prototype game is that large asteroid shatter into shards of that asteroid instead of spawning smaller versions of the asteroid.

## Quick Start
To run my code you will need to install the latest stable version of unity and create a new project.
and import my code and assets

## Usage
You should be able to play the game from the unity editor once its imported.
